5.2 MLM / Commission System

AspectDetail
Tree StructureUserTree model: user_id, upline_id, level. Unlimited depth. Built automatically on member registration.
Income DistributionDistributeIncomeJob dispatched async on plan activation. Walks up tree distributing commission to each upline based on plan base_value and level multipliers.
Daily CapPer-plan setting. Excess income is "lost" and absorbed as AdminEarning (type: lost_capture).
Total Cap (Lifetime)Per-plan setting. Once hit, no more income credited. Admin absorbs overflow.
Repurchase Wallet10% of total_earned deducted and stored as repurchase balance for shopping.
Admin View/admin/incomes — full paginated list with earner and from-member details, export CSV
Member View/member/commissions — AJAX paginated JSON, displayed as commission table on dashboard

5.3 Withdrawal & RazorpayX Payout Flow

StepWhoDetail
1. Submit withdrawal requestMemberPOST /member/wallet/withdraw. Validated: active status required, bank details must be saved, RazorpayX must be configured, amount >= min_withdrawal, sufficient available balance.
2. Approve requestAdminPOST /admin/withdrawals/{id}/approve. Creates RazorpayX Contact → Fund Account → Payout. Deducts from member wallet_balance.
3. Reject requestAdminPOST /admin/withdrawals/{id}/reject. Updates status, no payout initiated.
4. Sync payout statusAdminPOST /admin/withdrawals/{id}/sync. Fetches latest status from RazorpayX API and updates record.
5. ExportAdminGET /admin/withdrawals/export — CSV with all withdrawal fields including UTR.
